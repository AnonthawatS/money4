# Handoff: Chat → Claude Code

ใช้ไฟล์นี้เป็นสะพานระหว่าง "คิดใน Chat" กับ "เขียนโค้ดใน Claude Code"
ใน Chat พิมพ์ว่า **"สรุปส่ง Claude Code"** แล้ว Claude จะเขียนสรุปตามแบบนี้ให้
บันทึกเป็น `docs/handoff/YYYY-MM-DD-ชื่อเรื่อง.md` ใน repo (หรือวางข้อความทั้งหมดใน Claude Code ได้เลย)
