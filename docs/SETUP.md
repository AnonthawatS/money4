# เงิน 4 ก้อน — คู่มือติดตั้งเวอร์ชันใช้จริง (v2)

แอปเก็บข้อมูลไว้ในเครื่องก่อนเสมอ แล้วซิงค์ขึ้น **Google Sheet** ซึ่งเป็นฐานข้อมูลหลัก
บันทึกตอนไม่มีเน็ตได้ รายการจะรอส่งเองเมื่อกลับมาออนไลน์ และเปิดจากหลายเครื่องก็เห็นข้อมูลชุดเดียวกัน

```
มือถือ (PWA) ──ซิงค์──▶ Apps Script ──▶ Google Sheet
                          ├─▶ Claude API (AI, ไม่บังคับ)
LINE ────────────────────┘ (ไม่บังคับ)
```

ใช้เวลาตั้งค่าประมาณ 15–20 นาที

---

## ขั้นที่ 1 — สร้าง Google Sheet + Apps Script

1. สร้าง Google Sheet ใหม่ ตั้งชื่อเช่น `เงิน 4 ก้อน`
2. เมนู **ส่วนขยาย → Apps Script**
3. ลบโค้ดเดิม วางโค้ดจาก `apps-script/Code.gs`
4. ⚙️ Project Settings → ติ๊ก **Show "appsscript.json"** → วางเนื้อหาจาก `apps-script/appsscript.json`
5. เลือกฟังก์ชัน `setup` → **Run** → อนุญาตสิทธิ์
6. เปิด **Execution log** จดค่า `API_TOKEN` ไว้

ชีตที่ระบบสร้างให้

| แท็บ | เก็บอะไร |
|---|---|
| Transactions | ทุกรายการ (รายรับ รายจ่าย จ่ายบิลบัตร) พร้อมวิธีจ่าย |
| Debts | บัตรเครดิตและรายการผ่อน (มีบัตรกสิกร กรุงศรี ตั้งต้นให้ ยอด 0) |
| Goals | เป้าหมายการออม |
| Settings | สัดส่วน 40/20/20/20 เงินเดือนฐาน เกณฑ์เตือน |
| Categories | หมวดและคำหลักสำหรับ LINE |

> แก้ข้อมูลในชีตตรงๆ ได้ แอปจะดึงค่าล่าสุดมาเองตอนเปิดแอปหรือกดปุ่มซิงค์

## ขั้นที่ 2 — Deploy เป็น Web app

1. **Deploy → New deployment → เลือกประเภท Web app**
2. Execute as: **Me** / Who has access: **Anyone**
3. คัดลอก URL ที่ลงท้ายด้วย `/exec`

แก้โค้ดภายหลัง: **Deploy → Manage deployments → ✏️ → Version: New version** (URL เดิม)

## ขั้นที่ 3 — เอาแอปขึ้นเว็บ (GitHub Pages)

> ลิงก์ตัวอย่างบน claude.ai เชื่อม Google Sheet ไม่ได้ เพราะหน้าเว็บบน claude.ai ถูกจำกัดไม่ให้ติดต่อเว็บภายนอก
> ตัวที่ใช้จริงต้องวางไฟล์ในโฟลเดอร์ `pwa/` ไว้บนเว็บของคุณเอง

1. สร้างบัญชี github.com (ถ้ายังไม่มี) → **New repository** ตั้งชื่อ เช่น `money4` (Public)
2. **Add file → Upload files** → ลากทุกไฟล์ในโฟลเดอร์ `pwa/` ขึ้นไป → Commit
3. **Settings → Pages** → Source: Deploy from a branch → Branch `main` / `(root)` → Save
4. รอ 1–2 นาที จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/money4/`

## ขั้นที่ 4 — เชื่อมแอปกับ Sheet

1. เปิดลิงก์จากขั้นที่ 3 บนมือถือ
2. กด ⚙️ → **ที่เก็บข้อมูล** → ใส่ Web app URL และ API token → **เชื่อมต่อ Google Sheet**
3. ป้ายมุมขวาบนจะเปลี่ยนเป็น 🟢 **ซิงค์แล้ว**
4. ติดตั้งลงหน้าจอหลัก
   - iPhone: Safari → ปุ่มแชร์ → เพิ่มไปยังหน้าจอโฮม
   - Android: Chrome → ⋮ → ติดตั้งแอป
5. ตั้งยอดจริงที่แท็บ **หนี้/ออม**: แตะบัตรแต่ละใบ ใส่หนี้เก่าตอนเริ่มและยอดที่ตั้งใจลดต่อเดือน เพิ่มรายการผ่อนและเป้าออม
6. ตั้งเงินเดือนฐานที่ ⚙️ → ฐานงบประมาณ

ความหมายของป้ายสถานะ

| ป้าย | ความหมาย |
|---|---|
| 🟢 ซิงค์แล้ว | ข้อมูลตรงกับ Sheet |
| 🟡 กำลังซิงค์… | กำลังส่ง/ดึงข้อมูล |
| 🔴 รอส่ง n | ออฟไลน์ มีรายการรอส่ง จะส่งเองเมื่อมีเน็ต (แตะป้ายเพื่อลองใหม่) |
| 🔴 ซิงค์ไม่ได้ | ตรวจ URL / token / การ Deploy (แตะ ⚙️ ดูรายละเอียด) |

## ขั้นที่ 5 (ไม่บังคับ) — เปิด AI ในแอปจริง

บน claude.ai แอปใช้ AI ผ่านบัญชี Claude ของคุณ แต่บน GitHub Pages ต้องให้ Apps Script เรียก Claude API แทน

1. สร้าง API key ที่ console.anthropic.com (มีค่าใช้งานตามจริง รุ่น Haiku ถูกและเร็ว เหมาะกับการแยกรายการ)
2. Apps Script → Project Settings → **Script Properties** → Add
   - `ANTHROPIC_API_KEY` = key ของคุณ
   - `AI_MODEL` (ไม่ใส่ก็ได้) ค่าเริ่มต้น `claude-haiku-4-5-20251001`
3. Deploy เวอร์ชันใหม่ → เปิดแอป กดป้ายซิงค์ → การ์ด ✨ และ AI ในแชทจะเปิดใช้งาน

ถ้าไม่ใส่ key แชทยังใช้ได้ด้วยตัวแยกรายการพื้นฐาน (จับคำ เช่น ข้าว กาแฟ น้ำมัน รูดกสิกร)

## ขั้นที่ 6 (ไม่บังคับ) — LINE

1. สร้าง LINE Official Account → เปิด Messaging API
2. LINE Developers → Channel access token (long-lived) → Issue
3. Webhook URL = URL `/exec` → เปิด Use webhook → ปิด Auto-reply และ Greeting
4. Script Properties → `LINE_TOKEN` = token
5. แอดเพื่อน OA แล้วพิมพ์ `ผูก <PAIR_CODE>` (ดูใน Log ตอน setup)
6. รัน `installTriggers` ถ้าอยากให้เตือนตอน 3 ทุ่มเมื่อยังไม่บันทึก

คำสั่ง: `ข้าว 60` · `กาแฟ 60 รูดกสิกร` · `+คอมขาย 3000` · `จ่ายบิลกสิกร 2500` · `สรุป` · `ลบล่าสุด`
เวอร์ชันนี้ LINE รับได้ข้อความละ 1 รายการ และเมื่อบันทึกจากแอปจนก้อนไหนใกล้เต็ม ระบบจะเตือนเข้า LINE ให้

## ความปลอดภัย

- API token, LINE token และ Anthropic key อยู่ใน Apps Script ของคุณเท่านั้น ไม่ได้อยู่ในไฟล์แอป
- token ของแอปเก็บในมือถือเครื่องที่เชื่อมไว้ อย่าให้คนอื่นยืมเครื่องไปตั้งค่า
- ถ้าสงสัยว่า token รั่ว: ลบ `API_TOKEN` ใน Script Properties → รัน `setup` ใหม่ → ใส่ token ใหม่ในแอป

## อัปเดต v3 — รายการประจำ · งบวันนี้ · อ่านสลิป · เช็กอินรายสัปดาห์ · พอร์ตลงทุน

**วิธีอัปเดต (ไม่ต้องรัน setup ใหม่ ข้อมูลเดิมอยู่ครบ)**
1. Apps Script: วาง `Code.gs` ตัวใหม่ทับ → Deploy → Manage deployments → ✏️ → Version: **New version** (URL เดิม)
2. รันฟังก์ชัน `installTriggers` อีกครั้ง เพื่อเปิดเตือนใหม่ทาง LINE
3. GitHub: อัปโหลด `index.html` และ `sw.js` ตัวใหม่ทับ → เปิดแอป 2 ครั้ง

แท็บ **Recurring** และ **Portfolio** และคอลัมน์ `rec`, `asset` ใน Transactions จะถูกสร้างให้เองตอนซิงค์ครั้งแรก

| ฟีเจอร์ | ใช้ที่ไหน |
|---|---|
| รายการประจำ | แท็บ แผนเงิน → ประจำ ตั้งชื่อ หมวด ยอด วันที่ วิธีจ่าย / ถึงวันจะขึ้นการ์ดในแชทให้กด "จ่ายแล้ว" หรือ "ข้าม" / LINE เตือน 08:00 วันที่ครบกำหนด |
| วันนี้ใช้ได้อีก | แถบบนแชทและหน้าภาพรวม = (เงินเหลือก้อนจำเป็น + ก้อนบัตร − รายการประจำที่ยังไม่จ่าย) ÷ วันที่เหลือ − ที่ใช้ไปวันนี้ |
| อ่านสลิป/ใบเสร็จ/บิล | ปุ่ม 📷 ในแชท ต้องมี AI (เปิดใน claude.ai หรือใส่ ANTHROPIC_API_KEY) |
| เช็กอินรายสัปดาห์ | ขึ้นในแชทครั้งแรกที่เปิดแอปหลังวันอาทิตย์ / LINE ส่งทุกวันอาทิตย์ 20:00 |
| พอร์ตลงทุน | แท็บ แผนเงิน → ลงทุน บันทึก "ซื้อกองทุน/ซื้อหุ้น" แล้วเลือกพอร์ต ต้นทุนเพิ่มเอง มูลค่าปัจจุบันแตะเพื่ออัปเดตเอง |

## อัปเดต v4 — Money Life เป็นตัวหลัก + แก้ไขรายการ + ฉลองความสำเร็จ

**โครงไฟล์ตอนนี้**
- `pwa/` → แอป **Money Life** ตัวล่าสุด (อัปโหลดทุกไฟล์ในโฟลเดอร์นี้ขึ้น GitHub ยกเว้น `brand/`)
- `pwa/brand/` → ไฟล์โลโก้ (`logo-full.png`, `logo-mark.png`, `.svg`) ไม่ต้องอัปโหลด
- `apps-script/Code.gs` → หลังบ้าน **v4** ตัวล่าสุด
- `archive/pwa-old-ui/` → หน้าตาเดิม เก็บไว้เผื่ออ้างอิง ไม่ต้องใช้

**วิธีอัปเดต (ข้อมูลเดิมใน Sheet อยู่ครบ ไม่ต้องรัน setup ใหม่)**
1. Apps Script: วาง `Code.gs` ตัวใหม่ทับทั้งไฟล์ → การทำให้ใช้งานได้ → จัดการ → ✏️ → **เวอร์ชันใหม่** (URL เดิม)
2. เปิด URL `/exec` ในเบราว์เซอร์ ต้องขึ้น "Money Life API v4 กำลังทำงาน"
3. ถ้ายังไม่เคยรัน `installTriggers` หลังอัปเดต v3 ให้รันอีกครั้ง
4. GitHub: ลบไฟล์เก่าใน repo แล้วอัปโหลดไฟล์ใน `pwa/` แทน (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png, apple-touch-icon.png)
5. บนมือถือ ลบไอคอนแอปเดิม แล้วติดตั้งใหม่ จะได้ชื่อและไอคอน Money Life (ข้อมูลไม่หาย เพราะดึงจาก Sheet)

**ใหม่ใน v4**
| ฟีเจอร์ | วิธีใช้ |
|---|---|
| แก้ไขรายการ | แตะรายการในหน้าแรกหรือหน้ารายการ → **แก้ไข** แก้ยอด หมวด วันที่ วิธีจ่าย แล้วบันทึก (ซิงค์ขึ้น Sheet แถวเดิม) |
| ฉลองความสำเร็จ | ขึ้นเองเมื่อ ออมถึงเป้า · ผ่อนครบ · หนี้เก่าบัตรหมด · จบเดือนโดยทุกก้อนอยู่ในงบ ดูตัวอย่างได้ที่ ⚙️ → ดูตัวอย่างการฉลอง |

ระบบจำว่าฉลองเรื่องไหนไปแล้วไว้ใน Settings ของ Sheet (คีย์ `celebrated`) จึงไม่ฉลองซ้ำเมื่อเปิดจากเครื่องอื่น
ตอนเปิดแอปครั้งแรก สิ่งที่สำเร็จอยู่ก่อนแล้วจะถูกจำไว้เงียบๆ ไม่ขึ้นฉลองย้อนหลัง

## อัปเดต v5 — แผนแบ่งเงินเดือน 40/20/20/20 + บัตรและรายการผ่อน + ไอคอนใหม่
ไฟล์ที่เปลี่ยน: `pwa/index.html`, `pwa/sw.js`, `pwa/manifest.webmanifest`, ไอคอน `pwa/icon-192.png` `icon-512.png` `apple-touch-icon.png`, และ `apps-script/Code.gs` (ของ v4 เก็บไว้ที่ `archive/v4/`)
1. Apps Script: วาง `apps-script/Code.gs` แทนของเดิม → บันทึก → เลือกฟังก์ชัน `upgradeV5` → Run ครั้งเดียว (ข้อมูลเดิมไม่หาย)
2. Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy (URL เดิมใช้ต่อได้)
3. อัปโหลดไฟล์ในโฟลเดอร์ `pwa/` ทับของเดิมบน GitHub Pages
4. เปิดแอป ปิดแล้วเปิดใหม่ 1 ครั้งเพื่อโหลดเวอร์ชันใหม่ ไอคอนบนหน้าจอโทรศัพท์จะเปลี่ยนเมื่อลบไอคอนเก่าแล้ว "เพิ่มไปยังหน้าจอโฮม" ใหม่
5. ในแอป: แผนเงิน → บัตร/ผ่อน ใส่วันจ่ายบิลของแต่ละบัตร (✏️) แล้วเพิ่มรายการผ่อนที่มีอยู่ตอนนี้
